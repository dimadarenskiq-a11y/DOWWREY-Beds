# Changelog

## 1.0.0 — First public release

- Saved beds with up to 10 beds per player.
- Unique bed names with custom colors and icons.
- Active respawn bed selection.
- Friend Beds with server-side requests.
- Respawn at saved beds.
- Eye of Ender teleportation with configurable timing/cost profiles.
- 25-second default teleport cooldown.
- Damage-only cancellation with Eye refund.
- Broken-bed teleport handling.
- Responsive vanilla-style UI with smooth scrolling.
- GUI Scale 1–4 and fullscreen support.
- Configurable open/close keybind with Esc support.
- Client notifications instead of routine chat spam.
- Client and server configuration.
- Server-side validation and anti-spam/rate limiting.
- Support for singleplayer and dedicated servers.
