# DOWWREY Beds

DOWWREY Beds is a vanilla-style saved-bed, respawn and Eye of Ender teleportation system for Minecraft 26.3 on Fabric.

## Features

- Up to 10 saved beds per player.
- Unique names, custom colors and icons.
- Active respawn bed.
- Friend Beds and server-side requests.
- Respawn at saved beds.
- Eye of Ender teleportation.
- 6 / 3 / 1 second teleport modes costing 1 / 2 / 3 Eyes.
- 25-second default cooldown.
- Damage-only cancellation with Eye refund.
- Broken-bed handling.
- Responsive, vanilla-style UI with smooth scrolling.
- GUI Scale 1–4 and fullscreen support.
- Configurable keybind (F4 by default) and Esc to close.
- HUD notifications instead of routine chat spam.
- Client and server configuration.
- Server-side validation and rate limiting.

## Requirements

- Minecraft 26.3
- Fabric Loader 0.19.5+
- Fabric API 0.162.0+26.3
- Java 25+

## Development

Open the project in IntelliJ IDEA with Java 25 and the configured Gradle toolchain.
