# DOWWREY Beds 1.7.0 — Smart Beds QA

## Менеджер
- [ ] Статус «Доступна» отображается для безопасной точки в текущем измерении.
- [ ] В другом измерении показывается «Другое измерение».
- [ ] Для плохой позиции показывается «Нет безопасного места».
- [ ] Сломанная точка показывает «Сломана» красным.
- [ ] Расстояние отображается только в текущем измерении.
- [ ] Последнее использование корректно меняется после телепорта и respawn.
- [ ] Наведение на карточку показывает увеличенный preview выбранной иконки.

## Телепорт
- [ ] Кнопка блокируется во время cooldown.
- [ ] Опции блокируются при нехватке Ока Эндера.
- [ ] Причина блокировки отображается в tooltip.
- [ ] Серверная проверка остаётся окончательной.

## Friend Beds
- [ ] В списке игроков отображается заполненность слотов.
- [ ] При 10/10 кнопка отправки недоступна.
- [ ] Сервер повторно проверяет лимит при принятии.

## Сохранения
- [ ] Старые данные schema v2 загружаются с last_used_game_time = 0.
- [ ] Новые данные сохраняют last_used_game_time.
