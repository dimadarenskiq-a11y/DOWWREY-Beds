# DOWWREY Beds 1.8.0 — QA для 50–100 игроков

## Сервер

- [ ] Dedicated server с Minecraft 26.3 запускается без предупреждений DOWWREY.
- [ ] 50 игроков подключены одновременно.
- [ ] 100 игроков подключены одновременно.
- [ ] У каждого есть 0–10 сохранённых кроватей.
- [ ] Менеджер открывается без заметной задержки.
- [ ] Повторные запросы списка не создают нагрузку/спам.
- [ ] Friend Bed selector корректно отображает всех онлайн-игроков.
- [ ] 100 игроков не превышают лимит payload.

## Multiplayer actions

- [ ] Два игрока одновременно сохраняют кровати.
- [ ] Игроки одновременно редактируют свои кровати.
- [ ] Одновременно отправляется несколько Friend Bed запросов.
- [ ] Один и тот же запрос нельзя принять дважды.
- [ ] Один и тот же предмет/ресурс нельзя списать дважды из-за двойного пакета.
- [ ] Телепорт нельзя запустить второй раз до завершения первого.
- [ ] Cooldown проверяется сервером.

## Disconnect / restart

- [ ] Игрок выходит во время телепорта — Око возвращается.
- [ ] Игрок выходит во время Friend Bed запроса — запрос остаётся у получателя.
- [ ] Сервер останавливается во время активного телепорта — ресурсы возвращаются.
- [ ] Сервер корректно создаёт recovery-backup.
- [ ] После рестарта сохранённые кровати, active bed и запросы восстанавливаются.

## Измерения

- [ ] Overworld → Overworld.
- [ ] Overworld → Nether.
- [ ] Nether → Overworld.
- [ ] Overworld → End.
- [ ] Точка в незагруженном чанке не считается сломанной до фактической проверки.
