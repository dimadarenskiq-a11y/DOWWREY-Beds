# Иконки сохранённых кроватей

В 1.6.0 у каждой сохранённой кровати есть стабильная иконка. Иконка хранится как числовой ID, а не как ordinal Java enum, поэтому обновления мода не должны менять выбранную иконку игрока.

| ID | Иконка | Смысл |
|---:|---|---|
| 0 | Дом | дом / база |
| 1 | Шахта | шахта / рудник |
| 2 | Деревня | деревня / торговля |
| 3 | Замок | крепость / большой дом |
| 4 | Ферма | ферма / животные |
| 5 | Лагерь | временный лагерь |
| 6 | Портал | портал / переход |
| 7 | Лес | лес / природа |
| 8 | Незер | база в Незере |
| 9 | Край | база в Крае |

Иконку можно выбрать и при создании, и при редактировании. При Friend Bed она переносится вместе с цветом и названием.

Специальные состояния имеют приоритет над цветом линии:
- активная кровать — золотая линия;
- сломанная кровать — красная линия и надпись «Сломана / Broken».
