# DOWWREY Beds 1.5.0 — чек-лист

1. Открыть «Изменить кровать» и убедиться, что заголовок строго по центру.
2. Проверить одинаковые поля слева и справа на GUI Scale 1, 2, 3, 4 и в F11.
3. Изменить только название — цвет линии должен сохраниться.
4. Изменить только цвет — название должно сохраниться.
5. Изменить одновременно название и цвет — оба значения должны сохраниться после перезахода.
6. Выбрать активную кровать — линия должна оставаться золотой независимо от выбранного цвета.
7. Сломать кровать — статус должен оставаться красным и не использовать пользовательский цвет.
8. Проверить RU и EN.
9. Проверить редактирование длинного названия — элементы не должны выходить за панель.
10. Проверить, что повторное нажатие выбранного бинда и Esc по-прежнему закрывают меню.
