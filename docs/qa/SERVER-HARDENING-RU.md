# DOWWREY Beds 1.1.0 — Серверное усиление

В версии 1.1.0 добавлены небольшие серверные ограничения, которые не меняют обычный игровой процесс:

- запрос списка кроватей ограничен коротким серверным интервалом, чтобы клиент не мог бесконечно спамить пакетами;
- отправка кровати другу ограничена серверным интервалом 1 секунда;
- ограничения очищаются при отключении игрока;
- сервер проверяет состояние игрока при Shift + ПКМ и не открывает сохранение для spectator/мёртвого игрока;
- вся игровая логика по-прежнему остаётся сервер-авторитетной.

Эти ограничения не влияют на нормальную игру и не должны ощущаться обычному игроку.
