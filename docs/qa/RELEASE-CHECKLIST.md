# DOWWREY Beds 1.1.0 — Чек-лист релиза

## 1. Сохранение кроватей
- [ ] Shift + ПКМ по кровати открывает окно сохранения.
- [ ] Заголовок «Сохранить кровать» находится строго по центру.
- [ ] После сохранения окно менеджера автоматически не открывается.
- [ ] Вторую кровать можно сохранить сразу, не удерживая Shift во время нажатия «Сохранить».
- [ ] Максимум — 10 кроватей на игрока.
- [ ] Нельзя создать два одинаковых названия без учёта регистра: `Дом`, `дом`, `ДОМ`.
- [ ] Нельзя переименовать кровать в уже занятое название.
- [ ] Выбранный цвет линии сохраняется после перезахода.
- [ ] Для активной кровати слева от названия показывается ★, а линия имеет специальный активный цвет.
- [ ] Для сломанной кровати отображается «Сломана», красная линия и корректное состояние без зачёркивания.

## 2. Менеджер
- [ ] Название «Сохранённые кровати» находится строго по центру.
- [ ] Сообщение об отсутствии кроватей находится строго по центру.
- [ ] Колесо мыши прокручивает список плавно.
- [ ] Плавность работает вверх и вниз.
- [ ] Карточки и кнопки не выходят за область списка.
- [ ] GUI Scale 1 работает.
- [ ] GUI Scale 2 работает.
- [ ] GUI Scale 3 работает.
- [ ] GUI Scale 4 работает.
- [ ] F11 и возврат из F11 не ломают раскладку.
- [ ] Кнопки «Выбрать», «Телепорт», «Изменить», «Удалить» видимы и кликабельны.

## 3. Возрождение
- [ ] После смерти появляется возможность встать на сохранённой кровати.
- [ ] Можно выбрать любую доступную сохранённую кровать.
- [ ] Выбранная кровать становится новой ★.
- [ ] Сломанная кровать не используется для возрождения.
- [ ] После возрождения можно снова использовать Shift + ПКМ.
- [ ] После `/kill` соединение и управление игроком остаются полностью рабочими.

## 4. Телепортация
- [ ] 6 секунд — 1 Око Эндера.
- [ ] 3 секунды — 2 Ока Эндера.
- [ ] 1 секунда — 3 Ока Эндера.
- [ ] Сломанная кровать — 5 секунд / 3 Ока.
- [ ] После успешного телепорта действует cooldown 25 секунд.
- [ ] Под кнопкой показывается оставшееся время cooldown.
- [ ] Таймер cooldown обновляется прямо в открытом меню.
- [ ] Получение урона отменяет телепорт.
- [ ] Движение не отменяет телепорт.
- [ ] Прыжок не отменяет телепорт.
- [ ] Открытие меню не отменяет телепорт.
- [ ] При отмене Ока возвращаются.
- [ ] При полном инвентаре возвращённое Око не исчезает.
- [ ] При успешной телепортации стоимость окончательно расходуется.
- [ ] Эффекты и частицы появляются только во время телепортации.
- [ ] Сломанная точка удаляется только после успешного специального телепорта.

## 5. Кровати для друзей
- [ ] Можно выбрать другого игрока.
- [ ] Получатель получает запрос.
- [ ] Уведомление о запросе не появляется в чате.
- [ ] Принятие добавляет кровать только получателю.
- [ ] У отправителя эта кровать не появляется.
- [ ] Отклонение удаляет запрос.
- [ ] Запрос истекает через 5 минут.
- [ ] При принятии повторно проверяются лимит и уникальность названия.
- [ ] Если кровать была сломана до принятия, запрос корректно отклоняется.
- [ ] Повторная отправка запроса слишком быстро ограничивается сервером.

## 6. Уведомления и язык
- [ ] Уведомления не используют чат.
- [ ] Русские строки корректны.
- [ ] Английские строки корректны.
- [ ] Язык полностью берётся из настроек Minecraft.
- [ ] Нет отдельной кнопки смены языка в моде.

## 7. Настройки
- [ ] Уведомления можно отключить.
- [ ] Эффекты телепортации можно отключить.
- [ ] Отчёт cooldown можно отключить.
- [ ] Плавные анимации можно отключить.
- [ ] Настройки сохраняются после перезапуска клиента.

## 8. Сервер и безопасность
- [ ] Клиент не может сохранить кровать дальше допустимой дистанции.
- [ ] Клиент не может изменить чужую кровать.
- [ ] Клиент не может выбрать чужой UUID для управления своей кроватью.
- [ ] Сервер повторно проверяет наличие кровати перед телепортацией.
- [ ] Сервер повторно проверяет безопасную позицию.
- [ ] Сервер проверяет наличие Ока перед списанием.
- [ ] Повторные запросы на список не создают нагрузку без ограничения.
- [ ] Спам-запросов на передачу кровати нет: сервер применяет cooldown отправителю.
- [ ] При выходе игрока временные ограничения очищаются.
- [ ] Перезапуск сервера не уничтожает сохранённые кровати.
- [ ] Перезапуск сервера не уничтожает ожидающие запросы.
- [ ] Перезапуск сервера не создаёт бесплатную телепортацию.
