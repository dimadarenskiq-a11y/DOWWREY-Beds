# DOWWREY Beds 1.6.0 — чек-лист качества (RU)

## 1. Первый запуск
- [ ] При первом входе появляется только одно onboarding-окно.
- [ ] После «Понятно» onboarding больше не появляется после перезапуска клиента.
- [ ] Shift + ПКМ по кровати открывает сохранение.
- [ ] F4 открывает менеджер; назначенная в Controls клавиша также работает.

## 2. Подтверждения
- [ ] Удаление кровати требует подтверждения.
- [ ] Передача кровати другу требует подтверждения.
- [ ] Отмена возвращает к предыдущему экрану.
- [ ] Подтверждение не отправляется повторно двойным кликом.

## 3. Информация карточки
- [ ] Карточка показывает иконку, название, измерение, координаты и возраст точки.
- [ ] Overworld / Nether / The End локализованы.
- [ ] Пользовательские измерения отображаются безопасно как ID.
- [ ] Длинные названия не ломают карточку.

## 4. Multiplayer / server authority
- [ ] Сервер проверяет имя, владельца, лимит, цвет и иконку.
- [ ] Сервер повторно проверяет состояние кровати перед telepor/respawn/gift accept.
- [ ] Rate limit запросов не ломает обычную игру.
- [ ] Клиент не может изменить игровые правила локальным конфигом.

## 5. Измерения и безопасность
- [ ] Телепорт в Overworld работает.
- [ ] Телепорт в Nether работает.
- [ ] Телепорт в The End работает.
- [ ] Сломанная кровать не используется как обычная точка.
- [ ] Перед телепортом ищется безопасная позиция.
- [ ] Если безопасной позиции нет, ресурсы не списываются.

## 6. Серверный конфиг
- [ ] После первого запуска создаётся `config/dowwrey_beds_server.json`.
- [ ] Изменение `maxBeds` меняет лимит.
- [ ] `friendBedsEnabled` отключает передачу кроватей.
- [ ] `teleportEnabled` отключает телепортацию.
- [ ] `brokenBedTeleportEnabled` отключает аварийный телепорт.
- [ ] Значения времени/стоимости телепорта отражаются в клиентском UI.
- [ ] После изменения конфигурации сервер перезапущен.

## 7. Tooltips
- [ ] Кнопки выбора, редактирования, удаления и телепорта имеют понятные подсказки.
- [ ] Иконки в сохранении/редактировании показывают название при наведении.
- [ ] Опции телепорта показывают, что время и стоимость задаёт сервер.

## 8. Доступность и адаптивность
- [ ] GUI Scale 1.
- [ ] GUI Scale 2.
- [ ] GUI Scale 3.
- [ ] GUI Scale 4.
- [ ] F11.
- [ ] Очень маленькое окно.
- [ ] Кириллица и латиница в названиях.
- [ ] Навигация клавиатурой не оставляет невидимые виджеты активными.
- [ ] F4/бинд не перехватывается при вводе текста.

## 9. Зависимости
- [ ] Мод запускается только с Fabric Loader + Fabric API + Minecraft 26.3 + Java 25.
- [ ] Для базовой работы не требуется ImGui, GeckoLib, FranklyLib или YACL.
- [ ] Отсутствуют случайные обязательные внешние runtime-зависимости.

## Иконки кроватей
- [ ] Дом
- [ ] Шахта
- [ ] Деревня
- [ ] Замок
- [ ] Ферма
- [ ] Лагерь
- [ ] Портал
- [ ] Лес
- [ ] Незер
- [ ] Край

Иконка сохраняется вместе с кроватью и переносится при Friend Bed. Активная кровать всегда имеет золотую линию, сломанная — красную; пользовательский цвет не переопределяет эти специальные состояния.
